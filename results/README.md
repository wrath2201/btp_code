# Results Archive

This directory stores all JSON evaluation artifacts, raw `.npz` prediction arrays, and intermediate historical runs. 
To ensure strict provenance and avoid confusion, the artifacts are strictly categorized into the following three sections.

## 1. FINAL
**Location:** `results/multiseed/` (excluding scratch files)  
**Description:** These are the final, verified artifacts used to produce the benchmark results in the paper. They contain the five-seed evaluations for all models across the 34,800-row, 6-condition grouped dataset.
- `frozen_dualpq_seed[0-4].json` (Final proposed method)
- `dualpq_concat_seed[0-4].json` (Original hybrid proposed variant)
- `dasnet_seed[0-4].json` (Deep representation standalone)
- `mgcnn_seed[0-4].json` (External baseline reimplementation)

For a summarized list of the exact numerical results contained here, see `FINAL_RESULTS.md`.

## 2. HISTORICAL_PILOTS
**Location:** `results/historical_pilots/`  
**Description:** Earlier experiments that are preserved for research history but are **NOT** part of the final benchmark.
- For example, `dualpq_concat.json` is a pilot experiment run on a limited 30-group subset of the dataset. It does not represent the full benchmark performance.

## 3. HISTORICAL_DEBUG
**Location:** `results/historical_debug/`  
**Description:** Known buggy or intermediate artifacts retained strictly for provenance.
- For example, `frozen_dualpq_bugged/` contains the old ~3% performance artifacts. These were generated by an earlier buggy iteration of the training loop that incorrectly nested evaluation logic and mutated variables in-place. They are preserved to maintain a complete research audit trail but are **NOT** valid results.
