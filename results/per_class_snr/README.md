# results/per_class_snr

Per-class × per-SNR metrics for every classifier that can be reconstructed from
the committed artefacts. Generated by `scripts/eval_per_class_snr.py`; see
`docs/PER_CLASS_SNR_EVALUATION.md` for definitions, reproduction commands,
fidelity checks and known gaps.

## Layout

```
<model>/accuracy_heatmap.png     29 classes x 6 noise levels, one-vs-rest accuracy
<model>/precision_heatmap.png                                 precision
<model>/recall_heatmap.png                                    recall
<model>/f1_heatmap.png                                        F1
<model>/kappa_heatmap.png                                     Cohen's kappa (2x2)
<model>/per_class_per_snr.csv    all five metrics, long format, class names included
<model>/metrics.json             grids (mean and SD over seeds), per-SNR and pooled
                                 aggregates, and per-class support
summary.md                       aggregate tables per model + cross-model tables
compare_macro_f1.png             macro-F1 vs SNR, all models, error bars over seeds
compare_overall_kappa.png        Cohen's kappa vs SNR
compare_overall_accuracy.png     overall accuracy vs SNR
```

Heatmaps follow the style of `figures/fig2_class_snr_heatmap.png` (RdYlGn, 0–1,
annotated). `_reference_original_recall_heatmap.png` is the pre-existing recall
figure, kept alongside for visual comparison.

## Models present

| Directory | Seeds | Source |
|---|---:|---|
| `classical_ensemble_weighted_vote/` | 1 | refit, seed 0, `fast=False` — the ensemble selected in `results/results.json` |
| `classical_ensemble_geometric_vote/` | 1 | same refit; the strongest classical variant on average |

| `mgcnn_sdtransformer/` | 5 | `results/multiseed/mgcnn_sdtransformer_seed{0..4}_best.pt` |

never saved. See *Known gaps* in the doc.

## Reading these

- The test set is class-balanced (30 rows per class per SNR level), so macro
  recall, balanced accuracy and overall accuracy are numerically identical.
- One-vs-rest accuracy sits at 94–99% for every model at every SNR because true
  negatives dominate with 29 classes. It is not a headline number.
- With 30 samples per cell, one error moves a cell by 3.33 pp. Trust the
  aggregates and the multi-seed means, not individual cells.
- `mgcnn_sdtransformer/` seeds 1–4 were trained and evaluated on **different
  data partitions** (`split_seed == seed` in their stored configs, whereas every
  other model used `split_seed = 0`). Its spread mixes split variance with
  training variance and its rows are not paired with the other models'.
